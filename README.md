# LynxOffice Homebrew Tap

LynxOffice offers Homebrew formulae that install the LynxOffice MCP server and command-line tool on macOS.

> **Status:** the formulae arrive with the first release.

```bash
brew install lynxoffice/tap/lynxoffice        # the lynxoffice command
brew install lynxoffice/tap/lynxoffice-mcp    # the MCP server
```

| Formula | Installs | Builds come from |
|---|---|---|
| `lynxoffice` | the `lynxoffice` command | [lynxoffice-cli-mac](https://github.com/LynxOffice/lynxoffice-cli-mac/releases) |
| `lynxoffice-mcp` | the MCP server | [lynxoffice-mcp-mac](https://github.com/LynxOffice/lynxoffice-mcp-mac/releases) |

The repository is named `homebrew-tap` because Homebrew requires a tap's repository name to start with `homebrew-`.
